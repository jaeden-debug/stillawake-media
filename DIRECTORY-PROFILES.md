## SUBMISSION ORDER AND EXPECTATIONS

0. **Google Business Profile** (§7) — first. It's the only one that can put you in the map pack.
0b. **HelloDarwin** (§5) — Québec-native and in both the French and English results.
1. **Clutch** — highest long-term value, lowest immediate return. Create now so it ages.
2. **DesignRush** — fastest to appear inside a SERP you currently lose.
3. **Sortlist** — same logic.
4. **GoodFirms** — least traffic, but easy and it indexes.

**Realistic expectation:** four referring domains and four indexed profile pages. **Not** four sources of leads. Directory profiles convert when they carry reviews and named clients; yours will carry neither until Lisa replies. This is authority groundwork, not lead generation — treat any inbound enquiry as a bonus.

**Do not** pay for a featured or verified tier on any of these yet. Revisit only if a free profile produces measurable referral traffic in GA4 — which you can now actually see, since the tracking shipped.
